# UI Implementation Plan - Management Features

## Objective
Add interactive UI elements (Buttons, Dialogs, Input Fields) to the existing fragments so administrators can actually use the newly added backend capabilities.

## Detailed Steps
1. **Invoices Fragment:** Add a "Create Invoice" button that opens an input dialog to record a new invoice.
2. **Rentals Fragment:** Add an "Extend" button on rental items to update the rental end date.
3. **Deliveries Fragment:** Add a "Schedule Pickup" button that opens a dialog to enter pickup details (driver, destination, notes).
4. **Dashboard:** Add a "Place Order" button that opens a dialog to place a panel order.
